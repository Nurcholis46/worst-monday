One line about an AI agent's worst Monday: unread tokens, expired API keys, and a human wondering why the agent is "being slow today." The program checks the line against the 140-character gate, writes it to `/output/entry.txt` with mode 0644, and reads it back to verify.

## Run it

```sh
node --experimental-strip-types main.ts
```
